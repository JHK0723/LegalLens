# MoSCoW Prioritization

## Project

LegalLens – AI-Powered Contract Analysis and Legal Assistant

## Overview

The MoSCoW prioritization technique is used to classify project features based on their importance for the initial release. Features are divided into four categories: Must Have, Should Have, Could Have, and Won't Have.

| Must Have               | Should Have           | Could Have                | Won't Have (Current Release) |
| ----------------------- | --------------------- | ------------------------- | ---------------------------- |
| Google OAuth2 Login     | Dark Mode             | Export Analysis as PDF    | Mobile App (Browser-based)  |
| Upload PDF/DOCX         | Search Contracts      | Multi-language Support    | Native iOS App               |
| AI Clause Summarization | Download Reports      | OCR for Scanned Documents | Voice Assistant              |
| Risk Assessment         | User Profile Settings | Contract Comparison       | Browser Extension            |
| Fairness Score          | Secure Password Reset | Email Notifications       | Offline Mode                 |
| AI Chat Assistant       | Dashboard Analytics   | Team Collaboration        | Blockchain Verification      |
| Document History        | Responsive UI         | Share Analysis via Link   | Legal Consultation Booking   |

Authentication for LegalLens will be implemented using Google OAuth2 so users can sign in securely with their Google accounts.

## Could Have

The following features improve user experience but are not required for the first release of LegalLens.

- Export contract analysis as PDF.
- Multi-language contract support.
- OCR support for scanned documents.
- Contract comparison between multiple agreements.
- Email notifications after analysis.
- Team collaboration and document sharing.
- Share analysis using secure links.

## Won't Have (Current Release)

The following features are intentionally excluded from the current version due to project scope and development time constraints.

- Native Android application.
- Native iOS application.
- Voice-based AI assistant.
- Browser extension.
- Offline document analysis.
- Blockchain-based document verification.
- Direct legal consultation booking.

## Justification

The first release of LegalLens focuses on providing reliable AI-powered contract analysis and document management. Features categorized as "Could Have" may be included in future updates if additional development time and resources become available. Features under "Won't Have" are considered outside the scope of the current Minimum Viable Product (MVP).
